04 · Конвейер ИИ

Семь шагов от текста до сводки

ШагЧто делаетГде в коде

Сигнал · техническая часть

Пройди по шагам быстро. Шаг 0 — регулярки ещё до ИИ. Шаг 1 — быстрая модель возвращает строгий JSON, который мы проверяем zod: обезличенный текст, тип, последствия, near miss, факторы. Шаг 3 — привязка вживую, поэтому счётчик на экране меняется при менторе. Шаг 5 — разбор первопричин, где каждая мера получает силу по RCA². Шаг 6 — сводка для главврача, где модель не может сослаться на чужую больницу: id фильтрует код.

05 · Поиск повторов

Похожие сигналы находим по смыслу, а не по словам

768

размерность вектора, режим CLUSTERING

5

ближайших соседей в pgvector

3

голоса за одну закономерность

0,85

минимальное сходство

Цифры закономерности считает код, а не ИИ. Пакетный поиск — кластеризация со средней связью: 0,89 по стране и 0,86 внутри больницы.

Сигнал · техническая часть

T3, инновационность. Сигнал превращается в вектор по краткому описанию и обезличенному тексту. Если три из пяти ближайших соседей принадлежат одной закономерности и похожи сильнее 0,85, сигнал встаёт в неё. Голосование защищает от одного случайного соседа. Порог подобран на синтетике: сигналы одной закономерности дают 0,88–0,95; порог в переменной окружения. Счётчики считает код — ИИ не придумывает цифры.

Синтетический набор. Кластеризация нашла и один повтор, который мы не закладывали, — 5 сигналов про ампулы. Проверка: npm run eval. На реальных данных измерим на пилоте.

Сигнал · техническая часть

Мы не говорим «ИИ работает хорошо» — мы показываем цифры на размеченном синтетическом наборе. Тип события 89%, последствия 85% и все 100% с точностью до соседней ступени, near miss 97%. Все три заложенные закономерности найдены полностью, и нашлась одна, которую мы не закладывали. Сразу оговорись: на реальных данных цифры будут ниже, измерим их на пилоте.

07 · Приватность

Анонимность — свойство кода, а не обещание

Исходного текста нет нигде

Ни в колонках, ни в логах, ни в текстах ошибок

Нет входа, cookie, IP и user-agent

В потоке сигнала их просто не собираем

Дата и смена вместо времени

По точному времени можно вычислить автора

Отделение — от 5 сигналов

Меньше пяти — разрез не показываем

Полей для имён нет, только необязательная роль. Ключи Gemini и Supabase — только на сервере.

Сигнал · техническая часть

Ключевая фраза: «Мы не можем нарушить анонимность, потому что нужных данных просто нет». Исходный текст не хранится ни в базе, ни в логах. В форме нет входа, cookie, IP и user-agent. Время — только дата и смена. Разрез по отделению показываем только от пяти сигналов. Полей для имён нет. Не говори «полная анонимизация»: на свободном тексте гарантии нет.

08 · Безопасность

Закрыли то, что ломается за минуту

База закрыта из браузера

RLS включён без политик, ключ сервиса только на сервере

Лимиты запросов

30 в минуту без IP + фаервол Vercel: на 31-м — 429

Расходы под контролем

Лимит трат на Gemini, сигнал до 4000 знаков

Инъекции в промпт

Модель без инструментов, JSON по схеме и zod

Перед сдачей: ревью безопасности API и стресс-тест экранов — длинные тексты, пустые состояния, узбекский текст.

Сигнал · техническая часть

T2. Из браузера к базе не достучаться: RLS включён, политик нет, ключ сервисной роли только на сервере. Лимит в приложении не использует IP, а фаервол Vercel режет POST-запросы: проверили — на 31-м запросе за минуту приходит 429. Расходы на Gemini ограничены. Текст сигнала — это данные, а не инструкции: у модели нет инструментов, ответ проверяется схемой, а id в сводке фильтрует код.

Сигнал · техническая часть

T4 — знания команды. Тех-ментор ценит честное «здесь сделано просто, и вот почему». В демо экраны ролей открыты сознательно — данные синтетические. Если Gemini недоступен, сигнал не сохраняется сырым: человек видит ошибку и текст остаётся у него в форме; очередь с повтором — следующий шаг. Метка места в QR докажет, что человек видел плакат в больнице, но не скажет, кто он.
